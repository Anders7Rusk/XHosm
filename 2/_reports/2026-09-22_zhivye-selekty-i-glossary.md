# Живые селекты + битые глифы (иконки)

**Дата:** 2026-09-22 · **Коммит:** 9e8b84e · **Запрос заказчика:** «Не все компоненты до сих пор функциональные. Посмотри. Селект не работает, чипс разъехался и т.д.»

## Что нашли (аудит)

1. **Селект-витрины (без поведения):** в интерфейсе было три `ds-select-form`, которые выглядели как селекты, но не открывались и не переключались:
   - «Автообновление: 20 с» (Обзор сервера) — тот, что на скрине;
   - «По заявке (iikoOffice)» (панель «Выдача iikoUser», причина выдачи);
   - «service: prod» (вкладка «Конфигурация» сервера).
2. **«Чипс разъехался» = битая иконка.** Аудит всех 73 глифов интерфейса «по ширине» в шрифте Material Icons Outlined (глиф есть → ~20px; глифа нет → рендерится текст):
   - `database` — глифа НЕТ в шрифте: вместо иконки рисовался текст «database» шириной 120px → кнопка «SQL-студия» распухала до 234px и выглядела «разъехавшейся» (на скрине — «квадрат + надпись»);
   - `monitoring` — глифа НЕТ: «Victoria Logs» (кнопка) и ссылки «Cloud Alerts / Victoria / Metabase» (иконки снекбаров).
3. Кнопки и ссылки без обработчиков вне дропдаунов — не найдены (все живые).

## Что сделали

1. Три селекта заменены на рабочие дропдауны по механике прототипа (`xh-dd-host` → кнопка → `.xh-dd`), + IIFE «Э-35» (открытие/выбор/закрытие, Esc, клик мимо, снекбар):
   - «Автообновление»: значения 20 с / 60 с / 5 мин / 15 мин / Выключено (набор — из подсказки «Внутреннего порта»: «интервалы: Off / 20 / 60 / 300 / 900 с»);
   - «Причина выдачи»: По заявке (iikoOffice) / По заявке (Pyrus) / По звонку клиента / Внутренняя проверка (L3) — с записью в журнал (LIC);
   - «service»: prod / beta / test — «изменится после перезапуска службы (IIKOWEB)».
2. Битые глифы заменены на существующие: `database` → `storage`, `monitoring` → `monitor_heart` (включая иконки снекбаров).

## Проверки (живые клики)

- «Автообновление»: открывается, выбор «60 секунд» → лейбл «Автообновление: 60 с» + снекбар, список закрылся.
- «service»: открывается в «Конфигурации», выбор beta → «service: beta» + снекбар.
- «Причина выдачи»: открывается в панели iikoUser, выбор Pyrus → «По заявке (Pyrus)» + снекбар.
- «SQL-студия»: иконка 20px (`storage`), кнопка 134px (было 234px, иконка 120px).
