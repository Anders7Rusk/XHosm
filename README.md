# xHOSM — редизайн интерфейса

Рабочие материалы: переделываем интерфейс xHOSM в удобный и понятный, на дизайн-системе iiko.
Аудитория — поддержка L3 (основная), L3 Web, аналитики, инфраструктура, партнёры.

**Прототип:** `index.html` — черновик нового интерфейса (структура «Клиент и сервер»).
Ссылается на ДС из организации — относительный путь `../iiko-ds-web/`: файл должен лежать рядом с клоном `iiko-ds-web` (как остальные прототипы в контуре iiko-DS).

## Прототип

- `index.html` — черновик нового интерфейса на ДС (структура «Клиент и сервер»): Рабочий стол → Клиент → Сервер. Открывается локально — рядом с клоном `iiko-ds-web`.
- `xHOSM_структура_прототипа_выводы_v1.md` — почему структура именно такая: выводы из болей, сценариев и гипотез.

## Сборка документов

- `build_*.py` — скрипты генерации PDF (reportlab, шрифты DejaVu). Запуск: `uv run --no-project --with reportlab python <скрипт>.py`
