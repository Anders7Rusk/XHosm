# xHOSM — редизайн интерфейса

Рабочие материалы: переделываем интерфейс xHOSM в удобный и понятный, на дизайн-системе iiko.
Аудитория — поддержка L3 (основная), L3 Web, аналитики, инфраструктура, партнёры.

## Документы (PDF)

| Файл | Что внутри |
|---|---|
| `xHOSM_материалы_для_нового_интерфейса.pdf` | как устроен текущий интерфейс: панели, сущности, статусы, лимиты |
| `xHOSM_боли_и_замечания.pdf` | боли из Jira / вики / переписок, с источниками |
| `xHOSM_сценарии_работы_v1.pdf` | 20 операционных сценариев (черновик — на сверку с командой) |
| `xHOSM_сценарии_интерфейса_v1.pdf` | 30 клик-путей + блок-схемы (черновик) |
| `xHOSM_гипотезы_улучшений_v1.pdf` | 16 гипотез: что и как менять, как проверяем |
| `xHOSM_совмещение_с_процессом_v1.pdf` | привязка к процессу разработки (справочно) |

## Прототип

- `proto/` — черновик нового интерфейса на дизайн-системе (структура «Клиент и сервер»). Появится здесь по ходу сборки.

## Сборка документов

- `build_*.py` — скрипты генерации PDF (reportlab, шрифты DejaVu). Запуск: `uv run --no-project --with reportlab python <скрипт>.py`
